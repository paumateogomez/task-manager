# Task Manager

Simple task manager built with Python to practice clean code, Git, GitHub and project structure.

## Features

- View tasks
- Add new tasks
- Mark tasks as completed
- Delete tasks
- Validate user input
- Save and load tasks using JSON

## Technologies

- Python
- Git
- GitHub
