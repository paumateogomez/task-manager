# Task Manager

Simple task manager built with Python to practice clean code, Git, GitHub and project structure.

## Features

- Create tasks
- List tasks
- Mark tasks as completed
- Delete tasks
- Save tasks in a local file

## Technologies

- Python
- Git
- GitHub
